## Simple Interest Calculator

This project includes a Bash calculator for computing simple interest from a principal amount, an annual interest rate, and a time period in years.

### Inputs

- `p`: principal amount
- `r`: annual rate of interest (as a percentage)
- `t`: time period in years

### Formula and output

The calculator uses the formula:

```text
Simple Interest = (p * r * t) / 100
```

It prompts for all three input values and prints the calculated simple interest. For example, a principal of 1000, rate of 5 percent, and time of 2 years produces simple interest of 100.

### Run the calculator

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

The script is provided for learning and demonstration purposes.
